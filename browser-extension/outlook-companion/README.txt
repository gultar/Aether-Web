BrowserOS Outlook Companion

This unpacked Manifest V3 extension lets BrowserOS automatically click Save on
pre-filled Outlook Web calendar events using your normal browser session.

BrowserOS copies this folder to:
  %LOCALAPPDATA%\BrowserOS\outlook-companion-extension

Load that persistent folder with Chrome/Edge > Extensions > Developer mode >
Load unpacked. The extension communicates only with BrowserOS on 127.0.0.1:8001
and Outlook Web on outlook.live.com.
